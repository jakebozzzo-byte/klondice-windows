# Klondice for Windows: update mirror

The Windows build of Klondice checks this repo's newest release (`latest.json`) when it starts, and offers to
update itself. Only the built zips are here; the game's source is private.

To install by hand: download `Klondice-<version>-windows.zip` from the newest release, unzip it anywhere you can
write to (Documents or the Desktop, not Program Files), and run `Klondice.exe`. Windows may warn it's from an
unknown publisher: More info → Run anyway.
